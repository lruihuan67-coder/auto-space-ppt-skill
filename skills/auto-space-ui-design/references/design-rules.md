# 凹凸时空 UI 设计规范

规范源于随 Skill 打包的 `assets/ui-starter/src/styles.css`、`src/admin.css` 和 `src/components/ui/`。若数值与组件实现冲突，以本包当前源码为准。品牌识别色与界面交互色用途不同。

## 色彩与主题

| 用途 | 亮色 | 暗色 | 使用方式 |
| --- | --- | --- | --- |
| 品牌蓝 `--brand-blue` | `#245CB5` | 同值 | Logo、品牌识别，勿改色 |
| 电光蓝 `--as-primary` | `#0D7CFD` | `#5BA8FF` | 主要按钮、选中态、关键数据 |
| 天际蓝 `--brand-sky` | `#00AAFF` | 同值 | 信息辅助、少量强调 |
| 页面背景 | `#F5F7FA` | `#0B1220` | 后台大面积底色 |
| 卡片表面 | `#FFFFFF` | `#142033` | 内容容器 |
| 主文字 | `#102541` | `#F3F7FF` | 标题与正文 |
| 次文字 | `#66758A` | `#A5B4C8` | 解释与元信息 |
| 分割线 | `#DFE6EF` | `#32445C` | 表格和输入控件 |

品牌辅助色橙 `#F74C25`、黄 `#FAB02F` 只在有语义需要时少量出现。成功、警告、错误状态使用组件既有语义 Token，不把这些颜色当页面主色。不要引入粉色或无依据的新品牌色。背景与卡片以中性灰度留白，电光蓝用于焦点，避免整页大面积高饱和蓝。

## 字体、形状与间距

- 中文优先 `Noto Sans SC`，回退 `PingFang SC` / `Microsoft YaHei`；英文和数字可用 Manrope、Inter。数字尽量使用等宽数字。
- 字号固定为 30 / 26 / 16 / 14 / 12 五档：30 指标数值、26 页面标题、16 区块与卡片标题、14 正文与操作、12 辅助信息。正文不小于 14，辅助信息不小于 12。
- 以 4px 为基础间距，常用 8、12、16、24、32px。按钮 `sm/md/lg` 高度为 36/44/52px；输入控件 `sm/md/lg` 高度约 32/40/48px；同一表单内 Input 与 Select 使用同一个尺寸。
- 圆角从 8/10/12/16px 逐级应用；按钮统一 8px，卡片通常 16px、无外描边、轻阴影，输入控件有边框。不要在白卡顶部或左侧加装饰色条。
- 后台常规正文和操作标签按可读尺寸设计，避免将核心信息压成 10–12px；标题、说明、数据和辅助标签建立明显层级。图标统一使用 Lucide，只允许 16px / 24px 两种尺寸、1.5px 描边、圆角端点；组件库以外的图标从 Lucide 同族补齐，不另画不同粗细的图形。
- 明暗主题通过 `.dark` 类切换，使用语义变量，不将亮色的十六进制值硬编码到暗色表面。

## 组件和场景

配套源码提供 `Button`、`Card`、`Badge`、`Field/Input/Select/Textarea`、`Checkbox/Radio/Switch`、`Tabs`、`DataTable`、`Dialog`、`Alert`、`EmptyState/Progress`、`MetricCard`、`AIJobCard`，以及 `MarketingHero`。从 `assets/ui-starter/src/index.ts` 查看公开导出，从对应 TSX 查看属性、尺寸与状态。后台示例 `AdminDashboard.tsx` 展示侧栏、指标、趋势、项目表格、弹窗和反馈的组合；组件展示页 `App.tsx` 展示变体。

企业后台优先保证筛选、查询、批量或主操作、状态反馈和数据密度的可读性；AI 产品页可使用智能体任务、知识库、工作流等语义。营销页可更自由地使用品牌视觉，但仍沿用 Logo、字色和层级。先按内容选择布局，不机械复制后台示例，也不要在所有页面使用相同的四卡片结构。
